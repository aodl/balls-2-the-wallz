# Graphite interface inventory

The existing workspace switches between account, roster, status, Help and arena context. The release changes the finish of those surfaces and keeps their markup, focus routing, geometry and application logic.

| Existing surface | Treatment and state cues |
|---|---|
| Contextual toolbar | Dark raised rail, metallic cap, short hard seam shadow. Neutral idle controls and pressed player-colour glyph/underbar. Disabled actions retain muted ink and native semantics. |
| Payment workspace | Three planes read as rail, stepped frame and recessed content. A ready packet adds a narrow machined upper-left accent and lower seam. Axis, person control, multiline memo and exact Copy remain in the approved grid. |
| From and To disclosure | Plain inline values open into a recessed selectable strip. Person control is a raised instrument with the existing icon and reassociation purpose. |
| Exact Copy controls | Shared raised-control bevel and neutral symbols. Enabled hover or keyboard focus can use payer accent. Disabled Copy remains visibly muted. |
| Payment notice | Cyan inset line and information icon with off-white text. Fee explanation remains in Help. Exact retained-payment warnings remain action-specific. |
| Update/Keep, manual copy | Warm replacement marker with a recessed decision area. The existing exact manual-value field shares the recessed form treatment. Neither requires a new window. |
| Account, Help, My cannon, saved instructions and outcomes | Common frame, rail, controls and section separators. Account entry uses a dark recessed field and existing privacy copy. Saved commands are local history. |
| Status, retry, operating details | Same graphite shell and button family. Verification details use neutral quiet ink. Preparation/placement notices use warm ink. |
| Identity, camera, audio and cycles | Compact raised buttons. The identity dot still names the declared account. Audio slash still carries mute state. No extra toggle. |
| Quantity and War Cry | Shared small instrument frame. Existing editor focus emphasis, dock visibility rules and pointer/focus locks remain. |
| Deflector/Join direction choices | Neutral keys, with accent under the selected direction. Existing cardinal/diagonal action semantics remain separate. |
| Loading, reconnect and error | Waiting label gains a compact opaque plate and retains its spinner. Renderer failure keeps a distinctly warm error surface. No new status transition. |
| Inspect tooltip and Locate | Pointer-transparent graphite tooltip/inspection note. Locate retains the original target and reuses the button bevel. |
| Speech, minimap and board | Speech uses the same neutral graphite under text. The minimap, physical structures, world colours and motion keep their existing rendering paths. |

Forced colours removes decorative frame detail and preserves system-highlight selected outlines. Reduced transparency uses opaque solid planes and shallower edges. Reduced motion keeps the existing no-transition path.
