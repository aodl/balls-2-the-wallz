# Local controls and payment authority

| Condition | Retained arena, camera and local draft | Wallet handoff | Global status |
|---|---|---|---|
| Initial acquisition | Wait for the first verified arena | Disabled | First-use spinner |
| Verified playback behind current reference | Continue only verified motion | Available when all current checks pass | Playback delayed |
| Routine Trickle gap | Render the authenticated endpoint. Inspect and edit as usual | Available with fresh witness and operational confirmation | Waiting for next on-chain update |
| Isolated failed observation | Keep the same session, camera and draft | Available while accepted witness and signed health still satisfy their limits | Current semantic status remains |
| Sustained read failure | Retain the board, selection, editors, inspection and navigation | Disabled | Connection delayed · retrying |
| Accepted witness older than 30 s or signed newer head still incomplete | Retain the validated board and draft | Disabled | Verification delayed |
| Signed operational confirmation unavailable or older than 15 s | Keep read-only/local controls | Disabled | Copy unavailable |
| Paused, protected or source unhealthy | Inspect and locally edit the last verified world | Disabled | Reason shown in the HUD |
| Verification/integrity failure | Retain only the last verified picture and available inspection | Disabled | Explicit verification error and Retry verification |

From and To disclosure and payer reassociation remain separate from the three
Copy buttons. The manual exact-value field and handoff disable with Copy.
Native Copy, API Copy and the manual handoff recheck authority on invocation.
Status-only changes add no row or overlay to the contextual panel. Draft edits
during degraded delivery remain local. Existing immutable packet keys and
Update/Keep semantics still govern recovery and replacement.
