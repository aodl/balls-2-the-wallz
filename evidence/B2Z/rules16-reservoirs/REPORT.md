# Rules16 reservoir qualification

The proposed successor preserves Rules15 placement for cannons and Diverters.
Reservoirs occupy their own tile and may touch existing structures. The target
must be empty, owned by the funding player, on an active island and at toroidal
Chebyshev distance four or greater from enemy territory. Construction is a
fixed 1,000,000 e8s plus the existing Ledger fee.

The [renderer review](../reservoir-visuals/REPORT.md) includes a connected basin,
an irregular channel and a basin across both toroidal seams. The runtime only
displays a cutout after verifying the authoritative occupancy. A local
construction proposal uses the ordinary selection indicator.

Chromium shows the [desktop quote](browser/reservoir-quote-1440.png),
[390px quote](browser/reservoir-quote-390.png), [320px quote](browser/reservoir-quote-320.png)
and [enemy clearance rejection](browser/reservoir-enemy-clearance-320.png).

actual renderer, composer and native clipboard. Rules15 hides the Reservoir
control. Rules16 copies the literal `RESERVOIR 4005` and quotes 0.01 ICP. Keep restores the original tile and packet. Update creates a fresh packet for the explicitly selected site.
[Browser results](browser/results.json).

An installed disposable run used the normal candidate, the exact hosted
Rules15 predecessor and the official local Ledger/Index interfaces. It
tested adjacent construction, three-cell rejection, four-cell acceptance,
overlap and underfunding. Seven new-epoch payments and one historical payment
received unique, exact receipts. The existing treasury and sources survived
the epoch migration. Nine authenticated publications independently reproduced
world bytes, exact events and scores, including the Rules16 checkpoint.
A separate observer pass opened the same authenticated artifacts across both
schema versions. The compiled predecessor correctly rejected restored
preparation metadata. The successor recovered, proceeded and retained
construction on re-upgrade.

The model, visual fixture and installed-disposable results exercise different
claims. The visual cost figures were recorded in Chromium with SwiftShader
on a shared host. Native mobile GPU performance has not been measured.
