## Browser evidence qualification

The executed offline mode loads the actual UI into an isolated Chromium document, uses the same ES-module source in in-memory data URLs, supplies recording responses from test fixtures and bridges SHA-256 to Python hashlib. The product files contain no such fixture transport or cryptography fallback.

This proves real browser layout, Canvas, application/control and failure-path behavior. ## What remains intentionally limited

Local pins are not IC certificates; replacing a complete recording and its pins can produce a different internally consistent replay. Final visual-state agreement is not proof of all intermediate game rules or scoring. The UI says offline replay and not IC-certified prominently.

The observer downloads state and compact render bytes. It verifies their full contents and the catalog's links, but does not claim to have downloaded the audit/score artifacts merely because their hashes are in that catalog. The visible territory table is not a payout ranking.

Queue capacity is four segments and 8 MiB of accounted input/projection bytes, not a total JavaScript heap bound. Delivery delays and 0.25 seconds per logical tick are demonstration presentation settings, not measured consensus latency. Metrics remain unavailable; no cycle or ETH-equivalent values are fabricated.

This is not a live paid game. No ledger/archive ingestion, authoritative cutoff fairness, canister certificates, payouts, typed per-record IC persistence or measured deployment capacity were added. S06's native and persistence limitations carry forward. Existing native source may still contain compiler or semantic defects.
