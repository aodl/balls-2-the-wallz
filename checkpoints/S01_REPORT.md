# S01 — Workspace, interface contracts and conformance

## Delivered

Five-package registry-dependency-free Rust workspace; an isolated IC read-only probe source; exact BTZ memo codecs; strict account/payment classification; source/lease/seal models; a genuinely resumable competitive-Life conformance kernel in JS and Rust; independent Python fixtures; generic offline segment commitment; usable memo/replay CLI; bounded check runner and complete ZIP tooling.

This intentionally includes useful Life/runtime work from S02 to make the checkpoint substantial. It does not claim to complete all of S02 or live S01 integration.

## What changed in the design

The eight-byte memo is one representation across legacy numeric and ICRC blob transports. Nonzero legacy-plus-blob combinations reject. Funding accounts are not principals. A delegated allowance spender is not granted cannon-command authority. Source completeness uses contiguous prefixes as the baseline; index/hints do not advance authority. Checkpoint seals are retained replay inputs. A portable state/cursor codec and canonical ordering make work-partition invariance directly testable.

The source review used the actual ICP interface revision already pinned by Jupiter, not an imagined common ledger API. Candid subsets are labeled manual/partial, normalized fixtures synthetic, and raw/live verification blocked.
